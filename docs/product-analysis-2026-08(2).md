# Media Memory 产品分析报告（市场调研）

- 调研时间截点：2026 年 8 月
- 视角：摄影师 / UP主 / Vlogger / 视频工作室 / 剪辑师
- 方法：产品代码与文档盘点；商用竞品公开信息（定价/现状，2025–2026）；开源项目扫描（GitHub）；创作者社区实证（B站 / 小红书 / Reddit / V2EX / Hacker News）

---

## 0. 摘要

1. Media Memory 所处的赛道——**个人级、本地优先的视频语义检索**（ASR + OCR + 向量 + 画面描述融合，带时间点证据回跳）——在 2026 年 8 月**没有直接对位的成熟产品**，商用与开源两端都是空白。
2. 最接近的功能竞品各有一道"绑定"的墙：Premiere Media Intelligence 和 Jumper 绑 NLE，Eagle 4.0 以图片为主，飞牛 Seek 绑 NAS 硬件，Apple/Google 绑自家相册与云，Twelve Labs / Azure Video Indexer 是企业云 API。
3. 需求端已被充分验证：影视飓风"找不到素材"话题 140 万播放；小红书"几 TB 素材一个个点开看"3249 赞 934 评论；Eagle AI 搜索获自发好评；screenpipe（21k★，YC S26）与 Immich（113k★）分别证明"本地记忆检索"和"照片语义搜索"可以做到爆发级。
4. 供给端反而在退坡：Photo Mechanic Plus 停售、Kyno 停运，**本地个人级视频素材管理出现真空**。
5. 分人群适配度：UP主/Vlogger 最高；剪辑师能力匹配但工作流在 NLE 内；小型工作室部分适配；摄影师最低（不支持照片）。
6. 主要风险：NLE 内置化、NAS 标配化、Eagle 补视频 AI 的三面挤压，叠加自身规模验收未完成与分发摩擦。

## 1. 被调研产品定位回顾

Media Memory 是本地优先的 macOS（Apple Silicon）个人影像检索工具：只读扫描本地/NAS 视频 → 按画面变化与停顿做内容感知分片（4–30s）→ 证据车道（Qwen3-ASR、11 语言句级对齐、Apple Vision OCR、Qwen3-VL 片段向量）+ 描述车道（Qwen3.8 自动结构化描述）→ SQLite FTS 字面检索与向量语义检索 65/35 融合 → 每条结果给出画面/语音/文字证据，点击按 `start_ms` 跳回原片播放。四项模型能力供应商中立可配置，默认本机回环，API key 入钥匙串，无遥测。明确不做：云端、自动剪辑、人脸识别、团队协作、非 macOS 平台。当前 v0.1.3（2026-08-28），约 129 项自动化测试全绿；真实库规模验收（Recall@10、长期稳定性）尚未完成，收藏/集合/导出（M5）未实现。

一句话定位：**它不"管理"素材，而是让素材在不被改动的前提下变得可搜、证据可核对、时间可回跳。**

## 2. 市场需求分析（分人群）

### 2.1 UP主 / 内容创作者 —— 适配度：最高

- **痛点证据**：小红书 @三此君（2026-06）"为大疆设备拍了几 T 素材，每次想找素材得一个一个点开看，真的要命"——3249 赞 / 5319 收藏 / 934 评论；影视飓风专门做了"关键素材被删！找不到素材？"（B站 140 万播放）；韩路游记"每天 2TB 素材怎么保存"。
- **现有做法**：百度/阿里网盘 + 硬盘/NAS 归档；Eagle 手动打标选片；文件夹规范。无语义检索、无时间码回跳。
- **需求正在主动找产品**：司波图"本地 NAS 里的 AI 素材中枢：搜空镜、审片、转代理一步到位"（B站 1.4 万播放）说明"AI 搜空镜"已是热门内容赛道；飞牛 Seek 类 NAS 内置功能正在收割这波注意力。
- **付费信号**：Eagle（¥199 买断）长期有交易与插件生态（V2EX 出码帖、用户自写同步插件）；NAS 千元级硬件支出普遍；"本地离线、不联网不传图"被明确当作卖点与付费理由。
- **为什么适配**：口播 ASR（找金句）+ 画面语义（找空镜/旧素材）+ 跳时间点（直接进剪辑）正好覆盖其三大高频动作；**中文 ASR 与中文语义检索是海外竞品的集体缺位**。

### 2.2 Vlogger —— 适配度：高

- 素材更"生活流"：多设备（手机/相机/无人机）、家庭记忆向。消费级巨头已完成用户教育——Apple Intelligence 相册语义搜索已覆盖视频，Google Ask Photos 用 Gemini 做自然语言找回忆；但两者**锁死在系统相册与云端**：无外置盘、无 NAS 库、无证据核对、隐私存疑。
- **机会**：把"一句话找回忆"的体验从系统相册延伸到任意本地/NAS 素材库，且数据不出门——这正是产品名 "Media Memory" 的本义，与"记忆检索"叙事天然契合。

### 2.3 剪辑师 —— 适配度：能力高、工作流低

- **痛点**：定位素材靠个人经验（小红书 @小冯剪辑师"剪辑师怎么找素材"4638 赞）；"整理命名上百个片段是剪辑最枯燥的部分"（Reddit 婚礼摄像师帖）。
- **威胁面也是这个人群**：Premiere 25.3 Media Intelligence 已把"语义搜素材"做成 NLE 内置功能，Jumper 占了插件位，Resolve 20 有转写检索——**剪辑师正被 NLE 截流，他们不愿意离开时间线**。
- **结论**：当前独立 App 形态对剪辑师是摩擦。中期通过收藏/导出（M5）、EDL/XML 或时间线桥接才有意义，不建议首发主攻。

### 2.4 视频工作室（小型/独立）—— 适配度：部分

- **痛点**：项目归档无行业标准答案（r/VideoEditing 2025-07 "raw 留不留、怎么备份"讨论）；历史 b-roll 无法检索，新人接手靠口口相传。
- **现有方案**：文件夹规范（`YEAR > Project > RAW/EDITED/MUSIC`）+ 多硬盘；团队级方案（Frame.io $25/月/5人、Iconik $139+/人/月起、CatDV/axle 报价制）对个人工作室过重。
- **结论**：单人/两人工作室可直接受益，但协作、权限、审片、代理工作流都不在产品边界内——只覆盖"找回"一环，作为次级人群。

### 2.5 摄影师 —— 适配度：最低

- **痛点**：照片散落多硬盘、无标签、翻文件夹找旧图（V2EX"180G 照片管理"111 回复，此类讨论 2012 年至今不断）。
- **但供给已内卷**：Lightroom 云端语义搜索、ACDSee 本机 AI Keywords、Mylio 本地语义、Excire 离线打标、Aftershoot/Narrative 选片 AI——**照片 AI 检索竞争激烈，视频才是普遍空白**。
- **结论**：产品当前不支持照片/EXIF，摄影师不在目标射程内；但"照片支持"是使"影像记忆"名实相符、打开这批高付费意愿人群的自然扩展方向。

### 2.6 共性需求

四件套痛点贯穿全部人群：**素材分散多盘、内容不可搜（只能搜文件名）、备份焦虑、隐私顾虑**。"用一句话搜素材并跳到时间点"的需求已被多方主动表达（司波图视频、Eagle AI 搜索好评、RenamerX 用户催其加语音识别、Show HN Matriq、r/ClaudeAI 用 Claude 定位 b-roll 帖）。个人工具付费锚点：¥199 买断（Eagle）～ $10–25/月订阅（海外个人带）。

## 4. 市场空白与差异化定位

四条空白带（2026-08 现状）：

1. **个人级桌面 + 本地优先 + 视频多模态融合索引 + 时间点证据回跳**：无直接竞品；
2. **中文语音/中文语义检索**：海外产品集体缺位，国内无同类（Eagle 停在图片）；
3. **本地个人视频 DAM 供给真空**：Kyno 停运、PM Plus 停售，老玩家退场而需求上升；
4. **时间点级证据回跳**只在云 API 与企业 MAM 存在，从未下沉到个人。

Media Memory 对应的四条护城河：**跨库不绑定**（任意本地/NAS 目录，vs 一切生态锁定）、**证据可核对**（结果给画面/语音/文字证据而非黑盒结论，检索工具里少见的诚实设计）、**数据不出门**（默认回环+无遥测，社区已验证这是付费理由）、**供应商中立 + 中文场景**。定位话术上建议与 Eagle（管理+浏览）和 NLE（剪辑）错位：**"不管理素材，只让素材可被找到"**。

## 5. 竞争风险

1. **NLE 内置化（最大威胁）**：Premiere Media Intelligence 已把语义搜索变成 NLE 标配功能，剪辑师人群将被截流；
2. **NAS 标配化**：飞牛/群晖/绿联把 AI 素材中枢做成系统能力，NAS 重度用户（恰是本产品画像）被硬件生态截流；
3. **Eagle 横向扩展**：v4 已有 AI 语义搜索，补视频 ASR/OCR 对其工程量不大，且有 ¥199 买断的用户心智与基数；
4. **消费级巨头**：Apple 若开放照片 App 的外置库/文件夹索引则威胁陡增；Google 云端路线与本产品的隐私人群错位，威胁较小；
5. **自身成熟度**：真实库规模验收（Recall@10）未完成；无公证分发的首次打开摩擦；四端点模型配置对非技术用户门槛偏高（内置 Worker 仅覆盖对齐/向量两项）；单人项目对抗多线巨头的迭代速度。

## 6. 机会与建议（分析结论，非路线图承诺）

1. **人群排序**：UP主/Vlogger 个人创作者（痛点最锐、竞品最弱、中文优势）→ 记忆检索向 Vlogger → 个人工作室 → 剪辑师（待导出/桥接）→ 摄影师（待照片支持）。
