# 隐私与数据边界

Media Memory 是本地优先应用：它不包含统计、遥测、崩溃上报或云端账号系统，也不会修改源视频。模型服务由用户逐项配置，可以位于本机或远程。

## 数据会去哪里

| 数据 | 用途 | 去向 |
| --- | --- | --- |
| 源视频元数据与抽样字节 | 扫描、身份与变化判断 | 原位置，只读 |
| 当前处理的视频完整副本 | 降低 NAS 反复读取并保证同一处理快照 | `Work/SourceCache/`，同一时间最多一个，全部处理车道结束后删除 |
| 片段音频 | ASR | 用户配置的语音识别 URL |
| 片段音频与已知转写 | 句子时间定位 | 用户配置的 alignment URL；默认由本机 Worker 处理 |
| 代表帧、文字与检索指令 | 多模态向量 | 用户配置的 embedding URL；默认由本机 Worker 处理 |
| 代表帧与 ASR/OCR 证据 | 生成片段画面描述 | 用户配置的 chat-completions URL |
| 模型测试音频与图片 | 验证接口、鉴权、模型和返回契约 | 只发送给正在测试的模型服务；测试素材由应用生成，不读取媒体库 |
| 启用 Bearer 的模型 API key | 请求鉴权 | macOS 钥匙串；只随对应模型请求作为 Bearer header 发送 |

默认配置的 HTTP 请求指向本机回环地址且明确为“无需鉴权”，对齐和向量走本地 Worker；这四项不会访问钥匙串。用户可以把任意 HTTP 能力改成其他本地或远程服务；只有明确选择 Bearer 时才读取和保存该能力的 key。应用不会判断服务是否可信。非本机服务应使用 HTTPS，普通 HTTP 会以未加密方式传输请求内容和 Bearer key。界面对非本机 HTTP 显示明确警告。

模型接口按能力定义，不按供应商定义。应用不会把同一份数据发送给未被该能力选中的备用服务，也不会在失败时自动切换模型。

## 本机持久化内容

应用数据位于：

```text
~/Library/Application Support/MediaMemory/
```

- `media-memory.sqlite`：媒体绝对路径、只读授权书签、片段时间、ASR/OCR、向量、描述和任务状态；
- `models.json`：接口类型、请求 URL、模型名称、鉴权模式和本地 Worker 路径，不含 API key；
- `Work/Frames/`：搜索结果与详情页使用的持久代表帧；
- `Work/SourceCache/`：当前正在处理的一个源视频完整校验副本，正常完成、移除媒体或下次启动清理；
- `Work/Runs/`、`Work/Prefetch/`、`Work/DescriptionRuns/`：处理中间音频和候选帧，正常完成后删除，异常中断后在下次启动清理；
- `Work/ModelTests/`：模型测试期间生成的短音频和图片，测试结束立即删除；
- macOS 钥匙串服务 `MediaMemory.ModelService`：只为明确启用 Bearer 的能力保存 API key，设置为仅本机、首次解锁后可用。旧版可能还留有 `MediaMemory.oMLX` 项；本机无鉴权配置不会为了清理它而主动访问钥匙串，可由用户在“钥匙串访问”中手动删除。

源位置的视频始终只读。临时完整副本不是长期媒体库，不能作为源视频备份；应用崩溃留下的副本会在下次启动时清理。

启动时不会批量解析媒体书签或探测 NAS/网络卷。只有扫描、实际处理源视频或播放时才解析对应根的安全书签；授权失效会显示非模态警告，由用户选择原位置重新授权。

## 删除与退出

- 移除整个媒体根会删除该根及其资产、证据、任务记录和当前源缓存；移除单个视频会删除片段、ASR/OCR、向量、描述和当前源缓存，但保留一条包含路径、指纹和文件元数据的排除记录，避免下次扫描重新纳入。两种操作都不触碰源位置的视频。
- 应用会立即尝试清理不再引用的代表帧。SQLite 删除不等于安全擦除，旧页在数据库压缩或整个数据目录删除前仍可能留在数据库文件的空闲页中。
- 若要立即清除全部派生数据：退出 Media Memory，删除上述 `MediaMemory` 目录；API key 需另行从 macOS“钥匙串访问”删除。请检查当前服务 `MediaMemory.ModelService`，以及升级前可能残留的旧服务 `MediaMemory.oMLX`。
- 删除应用本身不会自动删除 Application Support 数据或钥匙串项目。

## 发布仓库和 DMG 不包含什么

仓库的忽略规则排除了环境文件、本地数据库、常见个人音视频、签名凭据、`.media-memory/`、`test media/`、`.build/`、`DerivedData/`、`.DS_Store` 与编辑器用户目录。身份生成期间临时私钥和导入包始终加密，并在脚本退出时清理；生成完成后，发布私钥保存在发布者本机钥匙串，可按需另行导出加密 `.p12`。仓库只提交不含私钥的 DER 公钥证书作为身份基线。DMG 只包含已签名应用、MIT 许可证和安装说明，不包含证书私钥、备份、密码、本机配置、API key、数据库、源缓存、测试视频或模型权重。

提交和发布前仍应以实际文件清单、Git 历史秘密扫描和最终 DMG 解包检查为准，不能只依赖忽略规则。
